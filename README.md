# yt-userscripts

Userscripts for the YouTube desktop website.

| Script | What it does | Install |
| --- | --- | --- |
| [Auto Summarize (Multi-language)](auto-summarize/README.md) | Requests a video summary when YouTube's Ask feature is available. | [Greasy Fork](https://greasyfork.org/scripts/602107-youtube-auto-summarize-multi-language) |
| [Hide Live Chat by Default](hide-live-chat/README.md) | Hides automatically opened live chat. | [Greasy Fork](https://greasyfork.org/scripts/603730-youtube-hide-live-chat-by-default) |
| [Stop Autoplay](stop-autoplay/README.md) | Prevents autoplay when opening videos, live streams, or Shorts. | [Raw](https://raw.githubusercontent.com/csjune/yt-userscripts/main/stop-autoplay/yt-stop-autoplay.user.js) |

## Installation

Install [Violentmonkey](https://violentmonkey.github.io/) (Firefox) or [ScriptCat](https://scriptcat.org/) (Chrome), then use the install link above.

In Chrome, enable **Allow User Scripts** for the manager in `chrome://extensions`.
